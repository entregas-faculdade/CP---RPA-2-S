# CP - RPA (Automação de Processos Robóticos)

Projeto focado em RPA, contendo scripts para processamento e anonimização de dados de manifestações de clientes.

## Estrutura do Projeto
- `CP_RPA (1).ipynb`: Notebook Jupyter principal com as análises e rotinas de automação.
- `anonimizar_texto.py`: Script Python para ocultar informações sensíveis em textos.
- `manifestacoes_clientes_cp5.csv`: Base de dados utilizada no processamento.
- `Enunciado.pdf`: Documento com as especificações da atividade.
